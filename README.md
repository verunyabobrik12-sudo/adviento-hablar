# ¡A hablar! — 30 дней разговорной практики по испанскому

Одностраничный календарь из 30 «окошек»: каждый день открывается одно окошко с устным заданием
(тема или описание фото). Темы: семья, внешность, характер, профессии, распорядок дня, gustar,
город и улица, жильё, еда; в конце — первые шаги в прошедшем времени.

## Как работает
- Открыта только сегодняшняя ячейка. Будущие закрыты 🔒, прошедшие — закрыты:
  выполненные с галочкой, пропущенные серые.
- Прогресс хранится в браузере (localStorage). Для переноса на другое устройство —
  кнопка «Guardar mi progreso» даёт короткий код.

## Настройки (index.html)
- Дата первого окошка — константа `START` в начале скрипта.
- `?profe` в конце адреса — все окошки открыты (для проверки заданий).
- `?hoy=2026-11-03` — проверить, как сайт выглядит в другой день.
- Задания — массив `TASKS`; фото лежат в `img/`.
