# ¡A hablar! — Calendario de Adviento de español

Одностраничный адвент-календарь для практики говорения: 30 окошек, в каждом — устное задание
(тема или описание картинки). Порядок по грамматике: estar + gerundio и futuro perfecto →
pretérito indefinido → pretérito imperfecto (ближе к концу).

## Настройки
- Дата первого окошка — константа `START` в начале скрипта в `index.html`.
- `?profe` в конце адреса — режим преподавателя: все окошки открыты.
- Прогресс ученика хранится в браузере (localStorage).
- Задания — массив `TASKS` в `index.html`, их легко править.
